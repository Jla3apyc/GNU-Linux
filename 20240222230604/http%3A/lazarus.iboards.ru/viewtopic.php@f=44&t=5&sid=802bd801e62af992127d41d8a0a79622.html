Ubuntu 10.04 (Lucid Lynx) by Lazarus

Ядро Linux 2.6.32, десктоп-окружение Gnome 2.30, Xorg 7.4.



 Отличия от базовой версии
- Добавлены русская локализация, кодеки и дополнительное программное обеспечение;
- Кэш содержит драйверы видеокарт FGLRX (ATI Radeon) и на все версии видеокарт NVIDIA (с 96 до 195);
- Архиватор корректно отображает кириллицу в zip-архивах;
- Gnochm открывает файлы на кириллице;
- Samba понимает кириллические имена компьютеров в сети;
- Обновлен VLC-player;
- Openoffice - по умолчанию предлагает сохранить файлы в формате doc и xls;
- Googleearth и Skype адаптированы для работы при включенном Cairo-dock в режиме opengl;
- Для корректной смены курсора при включенных эффектах, в пункт меню "системные утилиты" добавлен пункт "Выбор курсора";
- Для смены темы Plymouth в пункт меню "системные утилиты" добавлен пункт "Выбор темы Plymouth";
- Устранен баг с floppy-дисководом;
- В пункт меню "системные утилиты" добавлен ярлык "Emerald window decorator" (пакет emerald-icon);
- Исправлен баг с keyring, связанный с несохранением паролей;
- Добавлены дополнения Mozilla Firefox (AdblockPlus, Flashgot, Get File Size, ImgLikeOpera, PhZilla, UnMHT, Яндекс.Бар);
- На рабочем столе используется одна нижняя панель (см. screenshot);
- На панель задач добавлен переключатель рабочих столов, подключенные носители теперь отображаются не на рабочем столе а в более привычном для начинающих пользователей месте - в трее, откуда их можно извлечь;
- Интегрированы обновления по 26.02.2011 г.
